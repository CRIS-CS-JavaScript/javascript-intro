# JavaScript intro Github pages

We have a [`javascript-intro` repository](https://github.com/CRIS-CS-JavaScript/javascript-intro)
cloned locally. I want to create a minialmist introduction to JavaScript, in markdown viewable as
Github pages.

* The target audience is ELL middle school to high school students.
* We want to be complete enough to attain core concepts
  (from a First Principles or Fundamentals approach).
  English text should be very concise and minimal, using simple English.
* We don't want to overwhelm with all the features available - just the essentials.
* However, there should be links to resources where they can dig deeper into the concept.
  Use Mozilla Developer Network (MDN) as the primary resource.
